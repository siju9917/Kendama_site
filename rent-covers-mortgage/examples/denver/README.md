# Worked example — Denver

This is a real, finished run so you can see the target output:
- `Map.html` — the interactive map that was produced (open in a browser).
- `Log.md` — the ranked log.
- `runs_sample/` — three raw `calculator.py` outputs, so you can see exactly what
  the calculator prints and which lines to parse into `properties.json`.

The Denver run analyzed 218 listings → 135 green. Your run for a different city
will look like this once you've gathered listings and run the calculator on them.
